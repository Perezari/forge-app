שאלות נפוצות

איך מתחברים?מעתיקים את מפתח הגישה מהאתר של Codemagic, בהגדרות החשבון תחת API token, ומדביקים אותו במסך הראשון של Forge. המפתח נשמר רק באייפון.
אפשר לראות את האפליקציה בלי חשבון?כן. במסך הראשון לוחצים על "לראות איך זה נראה בלי חשבון". ההדגמה מראה פרויקטים לדוגמה, והבנייה בה רק מדומה.
איך מוסיפים פרויקט?באתר של Codemagic, דרך החיבור שלו ל-GitHub. אחרי שמוסיפים, הפרויקט מופיע ב-Forge. בהגדרות בוחרים אילו פרויקטים יופיעו במסך הראשי.
איך נספרות הדקות?Forge סופרת אותן לפי הבניות של החודש ב-Codemagic, כל בנייה מעוגלת לדקה שלמה. חשבון אישי מקבל 500 דקות בחודש, ואם המכסה שלך שונה, אפשר לשנות אותה בהגדרות.
למה להתחבר ל-GitHub?זה לא חובה. עם GitHub רואים את הקומיטים של כל פרויקט ואת אלה שעוד לא נבנו, ובוחרים ענף לבנייה.
ווידג'ט, מסך הנעילה ו-Siriהווידג'ט מראה את הדקות ואת הבנייה האחרונה של כל פרויקט. בנייה שרצה מופיעה במסך הנעילה ובאי הדינמי. ואפשר לבקש מ-Siri: "תריץ בנייה של" ושם הפרויקט, "ב-Forge".
